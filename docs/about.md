# 关于本站

## 何以“时报”

  说实话，一开始这么做纯粹是图个乐子。

  之前，我一直保持着写出行日志的喜好。自从我在一次骑行后首次写了篇英文的纪录，题为：“[A Wild Ride Along River](en/posts/2026/04/02-AWildRideAlongRiver)”,一切开始变得不一样。我先用Ai进行了润色，并使用富文本给它包了个有模有样的期刊模板，发在了我们的网站TravelHub上。我甚至自己为它作单词注释，就像别人为真正的外刊做的那样。一切做好后，我为自己的“期刊”感到满意，我细细品味着平淡的出行日志变成英文时，有一种奇特的感受，“bringing an unfamiliar freshness”————就像我在这篇文章中所写的那样，I felt a sudden thrill。我感受到英文表达的魅力，这非常酷

  于是，就有了这个网站。它给平淡的日常记录提供了一个全新的视角，能让我们通过陌生的表达方式，重新发现生活的趣味和新意。往粗里说，是为了装B,往雅说，可以互鉴中英语言之美，学习语言表达的同异，同时提升自身的水平。做一个真正的外刊网站，放大那个原本的狂想。同时也希望更多人共享它。让自己的故事被更多人聆听，也聆听更多人的故事....

  在这里，你可以品读地道的英文写作，欣赏有趣的故事，分享旅行随笔...每篇文章都有来自AI自助或作者自己提供的翻译、注释，可以随时开启页面右上方的开关切换语言。如果感兴趣，你也可以进入我们的网站[TravelHub](https://fbll.asia/)来浏览纯中文的内容


  我们尽可能让所有人轻松随性地发表内容。但所有内容发布前都会经过管理者和AI的审核，如果某些内容让你感到不舒服，欢迎提供反馈。这里并没有刻意异化或宣扬某些事物观念，也并不是想主张什么；毕竟，最初只是为了好玩。Come on,Don't be serious.

## 如何食用

功能简介：

- **[Updated daily](en/posts)**: 浏览最新文章；
- **[archive](en/archive)**: 期刊目录；
- **[Release](/)**: 发表文章；
- **[Edit](/)**：编辑文章，支持Markdown与html编辑，富文本编辑器正在开发测试中....
- **[AI automatic](/)**: Ai辅助翻译、校准、单词注释与归档、索引；

- **[周刊模板](https://fav0.com)**：提供个性化模板，追求高级；
- **[评论互动](https://giscus.app/zh-CN#repository)** 为保证更多功能的评论，我们使用Giscus作为评论组件；
